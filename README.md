# C++ Programming Lab

A collection of C++ programming lab experiments completed as part of the academic curriculum. This repository contains **97 programs organized into 20 labs**, covering basic C++ programming, functions, arrays, strings, pointers, structures, object-oriented programming, inheritance, polymorphism, file handling, templates, and exception handling.

## ▶️ How to Run

Compile a program using `g++`:

```bash
g++ program.cpp -o program
```

Execute the compiled file:

```bash
./program
```

For Windows:

```bash
program.exe
```
